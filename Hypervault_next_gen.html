Tip: you are about to type the password into the vault file itself. If someone else could have changed this file (for example on a USB stick), open it with your own trusted copy of Hypervault instead: tab "Open vault file".

Changes made here only apply to this browser tab. The defaults are stored in this file: open it in a text editor and edit G_DEFAULT_SETTINGS near the top. Every vault you create carries a copy of this file, including its defaults. The scrypt values used for a vault are stored inside the vault, so a vault always opens, whatever the settings are when you open it.
